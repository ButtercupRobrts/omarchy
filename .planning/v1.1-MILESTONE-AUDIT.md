## Cross-Phase Integration (integration checker)

All seven requirement wirings traced end-to-end in code:

1. **Phase 4→6:** `--default-index 1` passed in the post-`--` position; argv → JSON `defaultIndex` → `Menu.qml` `openDmenu` → `selectedIndex` set before `rebuildDisplay()`; Enter selects medium.
2. **Phase 5→6:** one `quality` variable; identical `high|medium|low` whitelists in `main()`, `select_quality`, `transcode_video`.
3. **Phase 5→7:** `output_size_label` stats the final resolved `$output`, carrying both the quality suffix and dedupe `-N`.
4. **Phase 6→7:** estimate and actual both divide by 1048576 (MiB labeled "MB") — same scale; `~1 MB` floor vs `(<1 MB)` floor never contradict.
5. **E2E interactive:** file pick → media_type → format → resolution → quality → output_path → start toast → encode → clipboard → stat → done toast. Esc aborts silently at any prompt; done notification can never follow a failed encode.
6. **E2E positional:** `omarchy transcode f mp4 1080p low` validates pre-notification, no menus, no probes.
7. **Picture path:** no quality prompt, quality positional rejected, done notification reports size.

No dangling references: `usage()`, `# omarchy:args`, `docs/menu.md`, `manual/12`, `capture.md`, `GROUP_DESCRIPTIONS` all in sync.
