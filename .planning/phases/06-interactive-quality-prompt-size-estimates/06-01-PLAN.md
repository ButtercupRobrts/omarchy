# Plan 06-01: Interactive `Select quality` menu — `\t<tier>\t<subtext>` rows with `CRF N · ~N MB` estimates (mp4) / `N fps` (gif), `-- --default-index 1` pre-highlight, strip + re-validate, probes scoped to the interactive video branch

## Goal

The video transcode flow gains a `Select quality` step after format+resolution whose rows carry `CRF N · ~N MB` estimate subtexts for mp4 (ffprobe duration × the locked per-resolution/tier bitrate table + the audio term) and `N fps` subtexts for gif, with `medium` pre-highlighted via Phase-4 `--default-index` plumbing; the pick's subtext is stripped and re-validated before tier matching; pictures and non-interactive callers never see the prompt or pay for the probe. Locked decisions D-00a..i and D-01..D-04 from `06-CONTEXT.md` are implemented, not relitigated. One atomic, independently revertible commit (AGENTS.md rule + Phase-4/5 precedent).

Output: modified `bin/omarchy-transcode` + extended `test/shell.d/transcode-quality-test.sh`, one atomic commit.
</objective>

## Trust Boundaries

|| Boundary | Description |
||----------|-------------|
|| media file → ffprobe output → `awk -v` | crafted file yields attacker-controlled duration/stream strings crossing into arithmetic |
|| menu return → `quality` → filename/ffmpeg argv | the pick string comes back across the `omarchy-menu-select` process boundary carrying a subtext field |
|| `select_quality()` → `omarchy-menu-select` argv | the `\t<label>\t<subtext>` wire rows cross into the menu payload; a stray tab corrupts field parsing |

## STRIDE Threat Register

|| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
||-----------|----------|-----------|----------|-------------|-----------------|
|| T-06-01 | Tampering | ffprobe/stat output → `awk -v`/`[[ =~ ]]` in `video_duration`/`estimate_label` | high | mitigate | treat probe output as data: `=~ ^[0-9.]+$` on duration and `=~ ^[0-9]+$` on `stat` bytes BEFORE any `awk -v` injection (awk `-v` interprets C escapes — the regex is the boundary); `N/A`/junk → `duration=""` → D-03 qualitative fallback; never `eval`, never `(( ))` on probe output |
|| T-06-02 | Tampering | menu return `label\tsubtext` → `quality` → `output_path` suffix + ffmpeg argv | medium | mitigate | `select_quality` strips at the first tab AND re-runs the `high|medium|low` `case` on the stripped value — a foreign label fails with `Invalid video quality` + `return 1` inside the helper, before the `Transcoding…` notification (keeps the no-orphan-notification invariant; RESEARCH §6 recommendation) |
|| T-06-03 | DoS | probe hiccup under `set -euo pipefail` on a detached/keybind launch → silent abort mid-flow | high | mitigate | every probe is `$(… 2>/dev/null || true)`- or `if`-guarded; failure degrades to all-qualitative rows (cosmetic) — the script never dies between prompts; the menu-select empty-pick exit-1 propagation is the only sanctioned abort |
|| T-06-04 | Tampering | tab-bearing subtext or filename → option field splitting | low | accept | menu options are three fixed literal strings built in `select_quality`; subtexts are constants with no tabs; filenames never enter menu options (the file pick returns a path, not a row) |

must_haves.prohibitions (descriptor-less, flagged-unverified items surviving the prohibition recall pass — the honest prohibitions live in PITFALLS.md):
