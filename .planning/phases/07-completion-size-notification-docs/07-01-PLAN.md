## Trust Boundaries

|| Boundary | Description |
||----------|-------------|
|| output file → `stat` output → `awk -v` | the byte count of a filesystem object crosses into awk arithmetic and then into a user-visible notification body |
|| `$output` path → notification body | the size string crosses into `omarchy-notification-send` argv and over D-Bus into the notification daemon |
|| encoder exit status → notification ordering | the done notification must not fire when the encoder failed — `set -e` ordering is the enforcement |

## STRIDE Threat Register

|| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
||-----------|----------|-----------|----------|-------------|-----------------|
|| T-07-01 | Tampering | `stat` output → `awk -v` in `output_size_label` | high | mitigate | `bytes=$(stat -c %s "$1" 2>/dev/null || true)` then `[[ $bytes =~ ^[0-9]+$ ]] || return 1` BEFORE the `awk -v` assignment — awk `-v` interprets C escapes, so the digit-only gate is the boundary (same contract as the Phase-6 probes); non-numeric output fails the helper and the caller degrades to the plain body — never aborts under `set -euo pipefail` (T-07-degrade pin) |
|| T-07-02 | Repudiation/integrity | done notification claims a size for an output that doesn't exist | medium | mitigate | the done notification sits after `transcode_*` under `set -e`, so an encode failure aborts before it; the `FAKE_ENCODE_RC` harness row pins zero `Transcoded to` lines on failure so a future refactor can't reorder it (T-07-failure pin) |
|| T-07-03 | Tampering (TOCTOU) | output file swapped/deleted between encode and stat | low | accept | benign — worst case reports the swapped file's size or degrades to the plain body; no write occurs, the path is one the script itself computed (research §Security) |
|| T-07-04 | Injection | size string → notification body → D-Bus | low | accept | the body is a typed `s` parameter in busctl's `susssasa{sv}i` call (bin/omarchy-notification-send:184-199) and the label is digits + literal ` MB` by construction — nothing can be reinterpreted as options or hints |

No package-manager installs in this phase — no supply-chain row applies. No external API integration — the API-coverage checkpoint is satisfied by inspection (local bash CLI + D-Bus helper only).
</threat_model>
