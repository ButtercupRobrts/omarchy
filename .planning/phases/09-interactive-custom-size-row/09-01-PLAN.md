## Goal

The mp4 `Select quality` menu gains a `Custom size…` row that opens `omarchy-menu-input`, feeds the typed answer through the same `parse_target_size` → `plan_target` path as `--target`, re-prompts once on empty or unparseable input, and cancels cleanly on Esc — with zero QML and zero `omarchy-menu-select` changes (ROADMAP Phase 9, verbatim).

Output: modified `bin/omarchy-transcode` + extended `test/shell.d/transcode-quality-test.sh`, one atomic commit.
